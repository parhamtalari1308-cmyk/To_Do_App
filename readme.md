# پروژه To-Do List

یک سیستم مدیریت تسک‌ها (To-Do List) با استفاده از Django و JavaScript

## 📋 توضیحات پروژه

این پروژه یک برنامه مدیریت تسک‌ها است که به کاربران امکان می‌دهد:
- کاربران مختلف ایجاد کنند
- برای هر کاربر تسک‌های مختلف ایجاد کنند
- وضعیت تسک‌ها را مدیریت کنند (انجام شده/نشده)
- تسک‌ها را ویرایش و حذف کنند
- تاریخ ددلاین برای تسک‌ها تعیین کنند

## 🛠️ فناوری‌های استفاده شده

### بک‌اند
- **Python 3.8+**
- **Django 4.2.7**
- **SQLite** (دیتابیس)

### فرانت‌اند
- **HTML5**
- **CSS3**
- **JavaScript (Vanilla JS)**
- **AJAX** برای ارتباط با API
